# Model Card

## Model

The project provides feature-based baselines and an optional compact 1D-CNN for four-class ECG
emotion recognition experiments.

## Intended use

- educational and portfolio demonstration;
- reproducible machine-learning experiments;
- local signal-processing and model-inference prototyping.

## Out-of-scope use

The models are not medical devices and must not be used for diagnosis, treatment, triage, or
personal health decisions.

## Limitations

- performance depends on the dataset, label definitions, sensor placement, and preprocessing;
- subject-independent evaluation is required before making generalization claims;
- ECG artifacts and label transitions can materially affect predictions;
- dataset access and redistribution are governed by the dataset's own terms.
